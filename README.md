# 🔐 Featured Security Engineering Projects

### ☁️ [Azure Healthcare Security Landing Zone](https://github.com/hknapp518/Azure-Healthcare-Security-Landing-Zone)

**Cloud Security · Zero Trust · Azure Policy · RBAC · Private Link · Key Vault · KQL**

Designed and validated a healthcare-focused Azure security architecture using Management Groups, Azure Policy, RBAC, hub-spoke networking, NSGs, Private Link, Key Vault, customer-managed encryption keys, and centralized logging.

Rather than stopping after deployment, I deliberately tested the controls, identified policy scope and Azure platform dependency failures, corrected the implemented controls, retested them, and documented remaining production gaps through a **SOC 2/HIPAA security-readiness assessment**.

**Engineering focus:** Governance · Network Segmentation · Data Protection · Detection · Security Validation

**Data Security · DLP · Defender XDR · Microsoft Purview · Splunk**

## 🎯 Engineering Approach

<div align="center">

### DESIGN → BUILD → TEST → INVESTIGATE → REMEDIATE → VALIDATE

</div>

| Phase | Security Engineering Objective |
| :---: | --- |
| **01 · Design** | Understand the workload, threat model, requirements, and security boundaries. |
| **02 · Build** | Implement security architecture and preventive/detective controls. |
| **03 · Test** | Validate controls through realistic scenarios, negative testing, and failure conditions. |
| **04 · Investigate** | Analyze telemetry and determine what happened, why it happened, and the security impact. |
| **05 · Remediate** | Correct weaknesses and improve the security posture without unnecessarily disrupting operations. |
| **06 · Validate** | Retest the control and document evidence, residual risk, and production recommendations. |
